Simple Exporter

Herramienta de pipeline para exportar assets desde Blender directamente a una carpeta destino, con control de prefijos, sufijos y estructura de objetos.Pipeline tool to export assets from Blender directly to a destination folder, with control over prefixes, suffixes, and object structure.

¿Qué es?What is it?

Simple Exporter es un addon de Blender desarrollado en Python que automatiza la exportación de assets 3D. El addon añade un panel en el viewport desde donde puedes exportar objetos individuales o colecciones enteras con un solo clic, sin navegar los menús de exportación manualmente.

Simple Exporter is a Blender addon developed in Python that automates 3D asset export. The addon adds a panel in the viewport from which you can export individual objects or entire collections with a single click, without manually navigating export menus.

Implementación técnicaTechnical implementation

Construido sobre la Blender Python API (bpy). Registra operadores y paneles en el N-Panel del viewport 3D. Usa bpy.ops.export_scene.fbx() con los parámetros configurados por el usuario.

Built on the Blender Python API (bpy). Registers operators and panels in the 3D viewport N-Panel. Uses bpy.ops.export_scene.fbx() with user-configured parameters.

import bpy # Panel in the N-Panel class SIEMPLE_PT_ExportPanel(bpy.types.Panel): bl_label = "Simple Exporter" bl_space_type = 'VIEW_3D' bl_region_type = 'UI' bl_category = 'Exporter' def draw(self, context): layout = self.layout layout.prop(context.scene, "export_path") layout.prop(context.scene, "export_prefix") layout.prop(context.scene, "export_suffix") layout.operator("siemple.export_selected") layout.operator("siemple.export_collection")
