Simple Exporter

Addon de Blender · Herramienta de pipeline · Open Source

  • Python
  • Blender API
  • bpy
  • Open Source

Addon de Blender que automatiza la exportación de assets 3D desde un panel en el viewport (N-Panel): objetos sueltos o colecciones enteras con un clic.

Ver en GitHub 
operators.pydef export_selection(self, itemname, context, base_dir):
    props = context.scene.props

    prefix = props.prefix
    suffix = props.suffix
    name = prefix + bpy.path.clean_name(itemname) + suffix
    fp = os.path.join(base_dir, name)

    if props.file_format == "OBJ":
        options = self.load_operator_preset(
            'wm.obj_export', props.obj_preset)
        options["filepath"] = fp + ".obj"
        options["export_selected_objects"] = True
        options["apply_modifiers"] = props.apply_modifiers
        bpy.ops.wm.obj_export(**options)
        self.file_count += 1

    elif props.file_format == "FBX":
        options = self.load_operator_preset(
            'export_scene.fbx', props.fbx_preset)
        options["filepath"] = fp + ".fbx"
        options["use_selection"] = True
        options["use_mesh_modifiers"] = props.apply_modifiers
        bpy.ops.export_scene.fbx(**options)
        self.file_count += 1

Por qué existe

Nació de un problema real en mi flujo de Blender a Unreal. Cada exportación obligaba a repetir los mismos pasos manuales, y los errores de nomenclatura acababan como assets rotos en el motor.

Antes

  1. Seleccionar el objeto
  2. Archivo, Exportar, FBX
  3. Buscar la carpeta destino
  4. Escribir el nombre con su prefijo
  5. Ajustar las opciones
  6. Repetir con cada asset

Con el addon

  1. Seleccionar
  2. Pulsar Export

Qué hice

  • Un clic: exporta objetos sueltos o colecciones enteras.
  • Destino configurado una vez: la carpeta se guarda con la escena.
  • Nomenclatura automática: prefijos y sufijos para mantener la convención de nombres.
  • Por dentro: bpy y bpy.ops.export_scene.fbx(), con soporte de presets del operador.
  • Compatibilidad: Blender 3.x / 4.x.
